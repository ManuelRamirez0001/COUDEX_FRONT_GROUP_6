Una historia por contar

Ratón de Biblioteca es una plataforma de comercio electrónico dedicada a la literatura colombiana. Reunimos en un solo lugar libros de autores nacionales y ayudamos a pequeñas librerías y vendedores independientes a llegar a más lectores. Queremos construir una comunidad cercana y abierta, donde lectores y escritores puedan encontrarse a través de la literatura.

¿Qué ofrecemos?

Catálogo

El único catálogo de literatura colombiana en un solo lugar.

Diseño adaptable

Una experiencia de lectura y navegación fluida desde cualquier dispositivo.

Carrito de compras

Proceso de compra rápido, claro y seguro para tus libros favoritos.

Panel de administración

Gestión eficiente y centralizada de inventario, pedidos y usuarios.

Misión

Acercar la literatura colombiana a los lectores, facilitando el descubrimiento de autores y obras nacionales en un espacio digital sencillo, donde cada persona pueda encontrar su próxima lectura y conectar con las historias de su país.

Visión

Ser la plataforma de referencia para descubrir literatura colombiana, una comunidad donde lectores, escritores y librerías se encuentren y donde leer a nuestros autores sea cada vez más parte de la vida cotidiana.

Preguntas frecuentes

Explora nuestro catálogo, selecciona los libros que desees, agrégalos a tu carrito de compras y sigue los pasos del proceso de pago seguro para confirmar tu orden.

Sobre este proyecto

Ratón de Biblioteca es el proyecto integrador principal desarrollado por el equipo Coudex como parte del bootcamp intensivo de Desarrollo Web Full-Stack Java impartido por Generation. A través de esta plataforma combinamos creatividad, lógica y buenas prácticas de desarrollo para conectar a los lectores con la literatura colombiana. El sistema fue construido integrando tecnologías modernas para el cliente y el servidor:

  • Frontend: interfaz dinámica y responsiva con HTML5, CSS3, Bootstrap y JavaScript.
  • Backend: lógica de negocio, arquitectura de microservicios y API REST con Java y Spring Boot.
  • Base de datos y herramientas: modelado relacional en MySQL, control de versiones con Git / GitHub y metodología ágil Scrum.

  • Manuel Ramírez: desarrollo de la lógica visual del cliente con JavaScript y gestión de navegación.

Equipo Backend

Encargados de la arquitectura del servidor, la lógica de negocio y el modelado de datos para garantizar un rendimiento seguro y robusto.
