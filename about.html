Una historia por contar

Ratón de Biblioteca es una plataforma de comercio electrónico dedicada a la literatura colombiana. Reunimos en un solo lugar libros de autores nacionales y ayudamos a pequeñas librerías y vendedores independientes a llegar a más lectores. Queremos construir una comunidad cercana y abierta, donde lectores y escritores puedan encontrarse a través de la literatura.

Equipo de Desarrollo

Sobre este Proyecto Ratón de Libro es el proyecto integrador principal desarrollado por el equipo Coudex como parte del bootcamp intensivo de Desarrollo Web Full-Stack Java impartido por Generation. A través de esta plataforma combinamos creatividad, lógica y buenas prácticas de desarrollo para conectar a los lectores con la literatura colombiana. El sistema fue construido integrando tecnologías modernas para el cliente y el servidor:

  • Frontend: Interfaz dinámica y responsiva desarrollada con HTML5, CSS3, Bootstrap y JavaScript.
  • Backend: Lógica de negocio, arquitectura de microservicios y API REST con Java y Spring Boot.
  • Base de Datos & Herramientas: Modelado relacional en MySQL, control de versiones con Git / GitHub y metodología ágil Scrum

Equipo FontEnd

Encargados de dar vida visual y construir la experiencia interactiva de la plataforma, asegurando una interfaz intuitiva, atractiva y adaptable.

  • Santiago López: Diseño de interfaces, maquetación responsiva con Bootstrap y estructura general.
  • Manuel Ramírez: Desarrollo de la lógica visual del cliente con JavaScript y gestión de navegación.
  • Jenssen Quintero: Integración de componentes interactivos y optimización de la experiencia de usuario (UX/UI).

Equipo Backend

Encargados de la arquitectura del servidor, la lógica de negocio y el modelado de datos para garantizar un rendimiento seguro y robusto.

  • Felipe Ortiz: Arquitectura del servidor y desarrollo de servicios REST con Java y Spring Boot.
  • Andrés Flórez: Lógica de negocio, gestión de controladores y conexión con la base de datos en Spring Boot.
